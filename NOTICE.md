# Notices for Eclipse Project Handbook

This repository holds the Eclipse Foundation Project Handbook
(https://www.eclipse.org/projects/handbook/) as a site built on solstice-nuxt:
the handbook's text and images, converted from its published page into pages
(`content/`, `public/images/`), and the site's code.
