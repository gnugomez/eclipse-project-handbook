The `CODE_OF_CONDUCT` file should provide a copy of the Eclipse Foundation’s [Community Code of Conduct](https://www.eclipse.org/org/documents/community-code-of-conduct). The `CODE_OF_CONDUCT` file may have an extension, and should be placed in the root of all project repositories.

The Community Code of Conduct is provided in ([markdown](https://www.eclipse.org/org/documents/community-code-of-conduct/CODE_OF_CONDUCT.md)) format.
