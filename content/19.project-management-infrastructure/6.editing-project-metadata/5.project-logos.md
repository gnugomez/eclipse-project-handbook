Project Logos appear in the right navigation area on the project page. They also appear on summary or list pages (for example, the [Project List Page](http://projects.eclipse.org/list-of-projects)).

Any member of the project team can set the project’s logo. The logo will be resized to a maximum of 200x200 pixels. Project logos are considered trademarks of the Eclipse Foundation (see [Logos and Graphics](/promoting-your-project/promotion-resources/#logos-and-graphics) for more information).

> **Tip:** The Eclipse Foundation will use your logo to promote your project. Be sure to create your project logo with a transparent background so that it will display well on arbitrary background colours.

Any committer or project lead can set the logo for their own project. To set the project logo:

- Log into the PMI;

- Navigate to the [project page](/project-management-infrastructure/project-pages/);

- Click **Edit**;

- Open the section labelled *The Basics*;

- Upload your logo to the *Logo* field;

- Click **Save**.

> **Note:** On a [project page](/project-management-infrastructure/project-pages/), the PMI displays either the project logo or — when the project is in the [incubation phase](/incubation/) — the [incubation logo](/incubation/incubation-branding/).
>
> To exit from the incubation phase into a mature project, a project must meet all of the requirements and engage in a [graduation review](/releases-and-reviews/graduation-reviews/).
