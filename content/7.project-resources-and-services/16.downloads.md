The project is allocated space on the Eclipse download and archive servers.

Project artifacts (e.g. downloads) can be distributed via third party services (e.g. [Maven Central](/project-resources-and-services/external-resources/#maven-central)), but — where technically sensible — the Eclipse Foundation-provided infrastructure must be considered the primary source of project downloads.

Project committers can [upload project artifacts](https://gitlab.eclipse.org/eclipsefdn/helpdesk/-/wikis/IT_Infrastructure_Doc#downloads) to the project’s directory on the download server using the [Eclipse Foundation hosted build infrastructure](/project-resources-and-services/builds/). The [short name](/project-resources-and-services/identifiers/) is used to denote the area available to the project (e.g. `https://downloads.eclipse.org/dash` for the `technology.dash` project).
