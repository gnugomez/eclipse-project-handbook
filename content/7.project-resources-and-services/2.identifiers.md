Project resources make use of two sorts of IDs:

- **Short name**

  The short name is used in various parts of Eclipse Foundation infrastructure (e.g. the name of the project’s directory on the downloads and Git servers, and the URL for the [project website](/project-resources-and-services/project-websites/)). The short name may contain lowercase alphanumeric characters, dashes, and underlines; but may not contain periods.

- **Project ID**

  The project’s short name is joined with the short name of the parent project(s) to form the *project ID* for the project that is used as a key on services provided for the project by the Eclipse Foundation. The project ID is composed of between one and three segments, separated by a dot (.); each segment may contain lowercase alphanumeric characters, dashes, and underlines. The segments define a path to the project through the project hierarchy, with the first segment being a top-level project ID.

For example the "Eclipse Woolsey" project has a *short name* of `woolsey`; its *project ID* is `technology.dash.woolsey`, indicating that it is a subproject of the an Eclipse *Dash* project (`technology.dash`) which is itself a subproject of the *Eclipse Technology* (`technology`) top-level project.
