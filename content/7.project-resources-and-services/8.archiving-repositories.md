If a repository belonging to a project is unmaintained or deprecated and will not receive any further updates, it is good practice to clearly indicate that in the corresponding `README.md` and `SECURITY.md` files of the repository with a migration path if applicable.

Committers shall mark a deprecated repository as being `archived` either by using the [Self-Service of GitHub Resources](/project-resources-and-services/github/#self-service-of-github-resources) or by [opening a Help Desk issue](https://gitlab.eclipse.org/eclipsefdn/helpdesk) to request assistance from the Eclipse Infrastructure Team.
