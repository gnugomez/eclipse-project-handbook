title: "Issue Trackers"
description: "Eclipse projects must use an Eclipse Foundation-provided issue tracker."
---

Eclipse projects must use an Eclipse Foundation-provided issue tracker. Project teams may opt to use either the [Eclipse Foundation GitLab](/project-resources-and-services/gitlab/) instance or — for projects that use [GitHub](/project-resources-and-services/github/) — GitHub Issues instances associated with Eclipse Foundation-managed GitHub project repositories.
