Open source projects at the Eclipse Foundation are *required* to make use of certain Eclipse Foundation services:

- All project issues must be tracked in the issue tracker assigned to the project;

- Source code must be maintained in source code repositories assigned to the project ([Eclipse Foundation GitLab](/project-resources-and-services/gitlab/) or [Eclipse Foundation-managed GitHub](/project-resources-and-services/github/));

- All third party content used by the project must be [vetted](/intellectual-property/third-party-content/);

- Downloads (when provided) must be distributed via [an Eclipse downloads](/project-resources-and-services/downloads/) server;

- Developer (committer) communication must occur in the [dev-list](/project-resources-and-services/mailing-lists/#project-dev-lists) provided to the project by the Eclipse Foundation; and

- Projects must keep their [Project Metadata](/project-management-infrastructure/project-metadata/) up-to-date.

The Eclipse Foundation provides the following services (high level) for Eclipse open source projects:

- IT and Infrastructure

  - Git hosting on [GitLab](/project-resources-and-services/gitlab/) or [GitHub](/project-resources-and-services/github/) (including issue tracking, wikis, CI/CD pipelines, etc.);

  - Jenkins-based build infrastructure via our [Common Build Infrastructure](/project-resources-and-services/builds/);

  - Artifact [signing](/project-resources-and-services/signed-artifacts/);

  - [Mailing lists](/project-resources-and-services/mailing-lists/);

  - [Chat service](/project-resources-and-services/chat-service/) based on Matrix protocol;

  - IT support via the [Help Desk](https://gitlab.eclipse.org/eclipsefdn/helpdesk);

- Security

  - Security audits;

  - [Vulnerability reporting](/vulnerabilities/cve/) (the Eclipse Foundation is a CNA);

- [Promotion resources](/promoting-your-project/promotion-resources/)

  - Financial support to subsidise the creation of a [project logo](/promoting-your-project/promotion-resources/#crowdsourcing-a-project-logo);

  - The [Adopters Programme](/promoting-your-project/promotion-resources/#adopters-programme);

  - Space on our web server for a [project website](/project-resources-and-services/project-websites/);

- Intellectual Property

  - [Intellectual property due diligence](/intellectual-property/) support;

  - Legal framework and infrastructure to mitigate the legal risk associated with contribution via the [Eclipse Contributor Agreement](/contributing/eclipse-contributor-agreement/) (ECA) and Developer’s Certificate of Origin (DCO);

  - Guidance for projects to ensure that [legal documentation](/legal-documentation/) and [metadata](/project-management-infrastructure/) is provided in a vendor-neutral and consistent manner;

- Open source project governance

  - [Committer elections](/elections/committer-elections/);

  - Project trademark assistance and management;

- Specifications

  - A programme for creating [specifications](/specifications/);

- Thought leadership

  - Best practices based on industry trends (e.g., [SBOMs](/software-bill-of-materials/) and AI in open source)
